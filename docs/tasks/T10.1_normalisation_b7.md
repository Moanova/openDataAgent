## Points de vigilance
- **Représentation des nombres** : `xlrd` et `odfpy` lisent les nombres comme des flottants (`30.0`) ; `openpyxl` conserve l'entier (`30`). Les tests ont une représentation attendue par lecteur (pas de « normalisation » des types en v1 — reportée en v2 avec les métadonnées de schéma).
- **charset-normalizer** détecte `cp1252` (et non `iso-8859-1`) pour du latin-1 français — équivalent pour les caractères utilisés, mais le détail d'encodage peut varier selon les versions.
- **Tests CLI et logs** : le callback Typer réinitialise `_SILENCIEUX` à chaque invocation ; pour garder `--json` parsable quand des tests précédents ont activé les logs, TI-27 passe `--silencieux` en argument CLI (et non par monkeypatch).
- **`.xls` en lecture seule** : `xlrd>=2.0` ne lit plus les `.xlsx` (d'où `openpyxl` pour ceux-ci).
